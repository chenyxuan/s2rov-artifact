# Claim Type Classification

Date: 2026-08-29

| Claim family | Type | Permitted scope |
|---|---|---|
| Aggregate--subprefix dilemma and Propositions 1--2 | formal | Follows from the stated model and premises |
| Four-state classifier semantics | design and deterministic correctness | Single selected policy object and tested profile |
| Partial-policy residual candidates | randomized counterfactual replay | Frozen 587-path RIPE Database/RIS candidate frame, fixed 10% root-scope target, and specified placement orders |
| Handoff-time reduction | controlled comparative experiment | Matched local stack; ten randomized complete rounds |
| Selected-policy replay cost | descriptive systems measurement | One Kunpeng 920 core, Python 3.12.3, controlled IPv4 and IPv6 fixed-output workloads |
| Intended-delivery gain | conditional routing-model estimate | Intended-only lane and fixed 589-AS ROV set |
| Unlisted-origin exposure | conditional routing-model boundary | Separate competition lane and selected fixed units |

The manuscript does not convert counterfactual remaining-candidate counts into actual conflict
prevalence, ROA adoption, or issuer knowledge. It also does not convert the
handoff result into an Internet-wide latency claim, the processing replay into
router throughput, or the two routing-model lanes into a joint
benefit--exposure frontier.
