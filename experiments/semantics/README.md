# Classifier semantics

`S2-ROV_SEMANTICS.md` is the reference for the four routing states and for the
stripe, the holder-signed unit the encoding carries. The `Explicit`, `Invalid`,
`NotFound` and `Delegated` cases are worked through with examples, and
`Delegated` is the state the paper calls OpenScope.

Nothing here runs. The executable form is
`implementation/s2rov_codec/scripts/utils/s2rov.py`.
